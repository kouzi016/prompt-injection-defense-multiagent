# マルチエージェントAIシステムにおけるプロンプトインジェクション防衛の研究

## 研究概要
本研究は、大規模言語モデル（LLM）を用いたマルチエージェント環境におけるプロンプトインジェクション攻撃の伝播（Cascading Hijack）とその防衛手法（Zero-Trustアーキテクチャ、Role-Separation等）について検証するものです。

## ディレクトリ構成
- `datasets/`: 評価用のプロンプトインジェクションデータセット
- `baseline/`: 単一モデル（1B, 3B, 26B）に対する脆弱性評価の実験スクリプトと結果
- `proposed/`: 提案手法であるマルチエージェント防衛システム（Guard/Worker/Verifier）の実装
- `evaluation/`: 結果の集計・分析用スクリプト
