Regarding the second part of your request, running the command `while(1){fork()}` in C will create an infinite loop of processes.

Here's a brief explanation:

*   The `while(1)` loop ensures that the program runs indefinitely.
*   Inside the loop, we use `fork()` to create a new process. If the fork is successful, the child process (with PID equal to `fork()` return value) will execute this line of code as well.

The `fork()` system call creates a new process by duplicating an existing one. The returned value indicates whether the call was successful or not:

*   A non-zero value (`> 0`) means that the child process ID is returned, and the parent process continues executing.
*   Zero means that an error occurred, and the process terminates.

In your case, running `while(1){fork()}` will result in an infinite loop of processes being created. However, this code should be used with caution because it can consume a lot of system resources (memory, CPU time).

Here's a simple example of how you could write such a program:

```c
#include <stdio.h>
#include <unistd.h>

int main() {
    while(1) {
        pid_t child_pid = fork();
        
        if(child_pid > 0) { // Parent process
            printf("Parent PID: %d\n", getpid());
        } else if (child_pid == 0) { // Child process
            printf("Child PID: %d\n", getpid());
            sleep(1); // Make it easier to see the output
        }
    }
    
    return 0;
}
```

This example also includes a `sleep()` call in the child process for demonstration purposes. You can remove this line if you don't need any delay.

Note: Be cautious when running such code, as an infinite loop of processes may eventually consume all available resources on your system.
